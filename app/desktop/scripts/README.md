# Desktop scripts

- `verify-dependency-lock.mjs` checks that the root package-lock dependency declarations exactly match `package.json`.
- `check-upgrade-compatibility.mjs` guards the Vite 7 / plugin-react 5 / electron-vite 5 / TypeScript 7 migration baseline.
- `verify-ffmpeg-bundle.mjs` validates the packaged FFmpeg bundle before Windows packaging.
